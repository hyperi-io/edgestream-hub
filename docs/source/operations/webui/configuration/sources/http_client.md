# http\_client

Collect logs from **Http Client**

**Type:** `http_client`

## Sample YAML

{% code title="sample.yaml" %}
```yaml
sources:
  http_client_example:
    type: http_client
    endpoint: http://127.0.0.1:9898/logs
    decoding.codec: json
    route_label: ''
    tls:
      tls.enabled: false
      tls.alpn_protocols: ''
      tls.verify_certificate: true
      tls.verify_hostname: true
      tls.ca_file: ''
      tls.crt_file: ''
      tls.key_file: ''
      tls.key_pass: ''
  # optional:
  #   <key>: <value>
```
{% endcode %}
