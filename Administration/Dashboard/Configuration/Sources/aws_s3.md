# aws\_s3

Collect logs from **AWS S3**

**Type:** `aws_s3`

{% code title="sample.yaml" %}
```yaml
sources:
  aws_s3_example:
    type: aws_s3
    sqs.queue_url: https://sqs.us-east-1.amazonaws.com
    region: bytes
    auth.strategy: access_key_id
    auth.access_key_id: ''
    auth.secret_access_key: ''
    auth.credentials_file: ''
    decoding.codec: bytes
    route_label: ''
    tls:
      tls.enabled: false
      tls.alpn_protocols: ''
      tls.verify_certificate: true
      tls.verify_hostname: true
      tls.ca_file: ''
      tls.crt_file: ''
      tls.key_file: ''
      tls.key_pass: ''
  # optional:
  #   <key>: <value>
```
{% endcode %}
