# Sources

Sources are the input for events and logs into the Edgestream Hub.

Event sources can pull events from remote locations, such as office 365, or listen for events to be pushed to the edgestream hub such as syslog.

The edgestream hub supports a range of sources available, as well as a syslog quickstart configuration section for adding UDP and TCP syslog listeners.

## Adding a Source

To add a new event or log source, select the Create button in the top right of the main window.

Provide a name for the source, this is an alphanumeric descriptor and can have underscores or hyphins.

Select the source type.

When a source type is selected, essential fields will be displayed that must be configured for that particular source.

There may also be TLS settings depending on the source type, and additional optional settings for fine tuning the source.
